# 스파르타 부트캠프 챕터 3 - 3번 과제

## Pawn 물리 이동 시스템

`MovementComponent`를 사용하지 않고 `Pawn`의 `Tick`에서 직접 물리 법칙을 구현하여 이동을 처리했습니다.

### 물리 법칙을 이용한 이동

입력 함수에서는 실제 이동을 처리하지 않고, 입력값을 힘으로 변환하여 멤버 변수에 저장합니다. 이후 `Tick`에서 입력 힘과 중력, 공기 저항을 합산하여 가속도와 속도를 계산하고 실제 이동을 처리합니다.

#### 힘 계산

* 입력으로 발생한 힘을 `InputForce`에 저장합니다.
* 공중에서는 질량과 중력가속도를 이용한 중력 힘을 적용합니다.
* 속도에 비례하여 공기 저항을 계산하고 전체 힘에 적용합니다.

#### 가속도 및 속도 계산

* 뉴턴의 운동 법칙인 `F = ma`를 이용하여 전체 힘으로부터 가속도를 계산합니다.
* 계산된 가속도를 `DeltaTime`에 따라 속도에 반영합니다.
* 최종 속도와 `DeltaTime`을 이용하여 실제 이동 거리를 계산합니다.

이를 통해 입력에 따라 위치를 바로 변경하는 방식이 아니라 **힘 → 가속도 → 속도 → 이동**의 과정을 거치는 물리 기반 이동을 구현했습니다.

### 충돌 처리

`CapsuleComponent`의 크기를 기준으로 `FCollisionShape`을 생성하고 `SweepSingleByChannel()`을 사용하여 이동 경로의 충돌을 검사합니다.

* 이동하기 전 현재 위치에서 목표 위치까지 Capsule Sweep을 수행합니다.
* 충돌이 발생하면 충돌 지점까지 먼저 이동합니다.
* 충돌 이후 남은 이동 거리를 계산하여 충돌한 표면을 따라 이동하도록 보정합니다.
* 한 프레임에 최대 3회까지 충돌 검사를 반복하여 코너나 경사면에서도 남은 이동량을 처리할 수 있도록 했습니다.

### 관통 및 벽 충돌

이동 시작부터 이미 다른 물체와 겹쳐 있는 경우 `PenetrationDepth`와 충돌 면의 `Normal`을 이용하여 겹침 상태에서 벗어나도록 위치를 보정합니다.

충돌한 표면이 벽인 경우에는 남은 이동량을 충돌 면의 법선 방향과 비교하여 벽을 뚫고 들어가는 이동 성분을 제거합니다. 이를 통해 벽에 충돌했을 때 이동이 완전히 멈추는 것이 아니라 **벽을 따라 미끄러지듯 이동**할 수 있도록 구현했습니다.

### 경사면 처리

충돌한 표면의 `Normal.Z` 값을 이용하여 걸을 수 있는 경사면인지 판단합니다.

* `Normal.Z > 0.7`인 경우 이동 가능한 바닥 및 경사면으로 판단합니다.
* 남은 이동량을 충돌면에 평행하도록 투영하여 경사면을 따라 이동합니다.
* 속도 역시 충돌면에 투영하여 이동 과정에서 불필요하게 속도가 감소하는 현상을 방지합니다.

### 공중 상태 감지 및 처리

`bIsInAir` 변수를 이용하여 Pawn의 현재 공중 상태를 관리합니다.

* 매 프레임 충돌 처리를 시작할 때 `bIsInAir`를 `true`로 설정합니다.
* 이동 중 충돌이 발생하고 충돌 지점의 표면이 바닥으로 판단되면 `bIsInAir`를 `false`로 변경합니다.
* 따라서 해당 프레임에 바닥과 충돌하지 않았다면 공중 상태로 판단하고 중력을 적용합니다.
* `bIsInAir`의 상태에 따라 공중에서의 이동 제어력과 중력 적용 여부를 결정합니다.
  이를 통해 별도의 `MovementComponent`나 복잡한 상태 관리 없이 **충돌 결과를 이용하여 지상/공중 상태를 판단**하고, 그 결과에 따라 중력과 공중 제어를 다르게 적용했습니다.

## Enhanced Input

`PlayerController`에서 `Input Mapping Context`와 `Input Action`을 관리하고, 게임 시작 시 Mapping Context를 등록합니다.

### 6축 이동 및 회전

* XYZ 축을 이용한 이동
* Pitch / Yaw / Roll 회전
* 이동 입력은 힘으로 변환하여 저장한 뒤 `Tick`에서 실제 이동
* `Look` 입력을 이용한 3축 회전 처리

## 중력 및 공중 제어

* `bIsInAir`가 `true`일 때 중력을 적용합니다.
* `InAirControlScale`을 이용하여 공중에서 X/Y 방향의 이동 제어력을 감소시켰습니다.
* 지상에서는 일반적인 이동 제어력을 사용하고, 공중에서는 감소된 제어력을 적용합니다.

## GameMode

`GameMode`를 생성하여 기본 Pawn과 PlayerController를 등록했습니다.

* `DefaultPawnClass` → `AMyPawn`
* `PlayerControllerClass` → `AMyPlayerController`
